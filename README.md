# BuyBuddy 🛍️

เพื่อนช่วยจัดของเข้าห้องเช่าตามงบ — ตอบไม่กี่ข้อ ได้ลิสต์ของที่ต้องซื้อ เทียบราคาร้าน (Shopee / Lazada / TikTok Shop) พร้อมปฏิทินซื้อของใช้ซ้ำ

**Live:** https://buy-buddy-next.vercel.app

## ฟีเจอร์หลัก

- ตัวช่วยตั้งค่าห้อง 8 ข้อ (บอกงบ, จำนวนคน, ของที่มีอยู่แล้ว — รองรับห้องเช่าแบบมีเฟอร์)
- แนะนำเฉพาะของที่ยังขาด จัดตามหมวด พร้อมป้าย จำเป็น/แนะนำ/ถ้ามีงบ
- กระเป๋า + งบแบบเรียลไทม์ + ปฏิทินวางแผนซื้อของใช้ซ้ำรายเดือน
- เทียบราคาต่อร้านและลิงก์ไปซื้อจริง (แอดมินกรอกราคา/ลิงก์/รูปเอง)
- ล็อกอินอีเมลหรือ LINE เพื่อเซฟแผนไว้ในบัญชี

## Stack

Next.js 16 · React 19 · TypeScript · Tailwind v4 · Supabase · Vercel

## รันบนเครื่อง

```bash
npm install
npx supabase start        # ต้องมี Docker
npm run dev               # http://localhost:3000
```

สร้างไฟล์ `.env.local` ตามตัวแปรใน `CLAUDE.md` (หัวข้อ Env vars)

## ทดสอบ

```bash
npx vitest run
```
